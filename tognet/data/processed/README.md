# Bearbejdede kortdata

Upload følgende tre filer fra chatten til denne mappe ved hjælp af **Add file → Upload files** på GitHub:

- `jernbaner_DK.geojson` (2.310 objekter)
- `jernbaner_SE.geojson` (5.055 objekter)
- `jernbaner_DE.geojson` (49.971 objekter)

Alle tre er mindre end GitHubs browsergrænse på 25 MiB pr. fil. De indlæses først, når den besøgende vælger det relevante land på kortsiden. Data er generaliseret med 200 meter og skal ikke bruges til præcis routing.
